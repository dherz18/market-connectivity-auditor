# Sample Outputs

These reports are generated automatically each run and emailed as attachments to the designated recipient.

**`no_usage_report.csv`** — subscriptions with no login record at all. These are candidates for immediate cancellation.

**`inactive_users_report.csv`** — subscriptions where the last login was 30+ days ago. These are flagged for review — the subscriber may have changed roles, left the firm, or simply not need the feed anymore.

An email summary (see `sample_email.txt` in this folder) is sent alongside these attachments with the headline counts and total potential monthly savings.
